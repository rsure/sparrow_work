## 怎么读这些图

三份文档都是 **Mermaid** 写在 Markdown 里（仓库里没有图片二进制，改起来不用重新导图）。查看方式任选：

1. **VS Code**：装 `Markdown Preview Mermaid Support`，直接预览；
2. **GitHub / 部分 Markdown 编辑器**：原生渲染；
3. **导出成 SVG/PNG**（需要 Node）：
   ```bash
   npx -y @mermaid-js/mermaid-cli -i doc/链路/03-权限判断流程.md -o doc/链路/03.svg
   ```
   注意：`.md` 里有多个代码块时 mmdc 只认第一个，建议把要导出的 mermaid 块单独存成 `.mmd` 再导。

每张图下面都配了一份**文字版步骤**（有序列表）。图是给人扫的，列表是给搜索和 diff 用的，
两者内容一致；如果哪天只改了一边，那就是文档 bug。

## 一句话总览

```
用户输入
  └─► 后端 /api/chat/stream
        ├─ ① 可选：上下文压缩（超阈值才调模型）
        ├─ ② 可选：任务拆分（复杂请求才调模型）
        ├─ ③ 主循环：模型 ⇄ 工具（每轮工具调用都是一次模型往返）
        ├─ ④ 可选：子任务汇总
        └─ ⑤ 后台：记忆抽取（不阻塞回答）
```

其中 ③ 是唯一"必然发生"的模型调用；①②④⑤ 都是条件触发，这也是控制成本的关键。
