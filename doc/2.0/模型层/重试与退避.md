# B7 API 重试与限流退避（增补：改造后可动态加入）

> 依赖锚点：ARCH-1 factory。长任务 25 步迭代中任何一步 429 / 超时，现状是整体失败——这应按**常态**处理。

## 1. 设计

- **重试范围**：`ConnectionError` / `Timeout` / HTTP 429 / 5xx。
  **不重试**：401 / 403（密钥错误，重试无意义，直接提示「请到设置页检查密钥」）、内容审核拒绝。
- **策略**：指数退避 `backoff_base × 2ⁿ` 秒 + 抖动（jitter），上限 `max_retries` 次；用 `tenacity`，不自研。
- **实现位置**：factory 出口包一层，所有 provider 统一生效。
- **与熔断联动（UX-9）**：重试等待时间计入 `cost.max_duration_minutes`；重试成功不中断任务。
- **SSE 断连**：前端 EventSource 自动重连；重连后靠 checkpointer（ARCH-4）恢复现场，不重复整轮。

## 2. 设置项（27 规范）

`retry.enabled`（on）/ `retry.max_retries`（3）/ `retry.backoff_base_seconds`（2.0）。
