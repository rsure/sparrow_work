# B3 记忆演进：冲突 / 衰减 / 分级（增补：改造后可动态加入）

> 依赖锚点：MEM（`25-工作空间记忆方案.md`）落地。解决「记忆只增不改不忘」的三个问题：
> 偏好变了无法覆盖、旧记忆永不淘汰、用户级与项目级信息混在一级。

## 1. 设计

| 能力 | 规则 |
| --- | --- |
| **冲突覆盖** | 新记忆与旧记忆相似度落在 0.6~0.9「中间带」时，交裸模型判定「语义是否相反」；相反 → 旧记忆标记 `superseded`（软删，保留溯源），新记忆入库 |
| **衰减** | 每次检索命中 `hit_count +1`；定期（每周）把 30 天未命中且 `importance ≤ 2` 的记忆降 1 级；降到 0 软删 |
| **分级** | `memories` 表加 `scope` 字段：`workspace`（现状）/ `user`（跨工作区，如「用户偏好中文注释」）；user 层注入所有工作区，workspace 层仅本区 |
| **抽取分级** | 抽取 prompt 增加 scope 判断：与具体项目相关 → workspace；与用户习惯相关 → user |

## 2. 改动文件

| 动作 | 文件 | 内容 |
| --- | --- | --- |
| 扩展 | `backend/app/entity/memory.py` | 加 `scope` / `superseded_by` / `hit_count` / `last_hit_at` 字段（Alembic migration） |
| 扩展 | `backend/app/services/memory_service.py` | 冲突判定 / 衰减定时任务 / 分级检索注入 |
| 扩展 | `backend/app/schemas/` | 接口出入参加 `scope` |

## 3. 设置项（走 27 规范声明式注册）

`memory.dedupe_threshold`（0.9）、`memory.importance_min`（2）、`memory.auto_extract`（抽取与注入拆开）。

## 4. 验收标准

- [ ] 告诉 agent「以后注释用英文」后，旧的「偏好中文注释」记忆被覆盖标记，不再注入。
- [ ] user 层记忆切换工作区后仍注入；workspace 层不跨区泄漏。
- [ ] 衰减任务跑过后，长期未命中的低价值记忆自动降级 / 软删。
