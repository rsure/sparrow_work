## 纳入原则

1. **不动主骨架**：每个模块只允许「新增文件 + 小步扩展」，主改造已定稿的协议（SSE 事件字段、工具输出外壳、设置注册）**只消费不修改**。
2. **设置走规范**：新模块配置全部按 `27-设置体系规范.md` §3 三步接入，零接口改动。
3. **可独立回滚**：每个模块可独立开关（默认 off 的优先），关闭后行为与加入前一致。
