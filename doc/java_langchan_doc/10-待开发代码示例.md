## 1. 2.11 顺手修：审计按工具过滤无效

> **文件**：`backend_java/src/main/java/com/example/backendjava/service/impl/AuditServiceImpl.java`
> **改法**：整文件替换（原文件缺少模块说明、import 注释，还带一个无用 import，一次补齐）。

**问题回顾**：`Specification#and(...)` 返回的是**新对象**，原来的 `spec.and(eq("tool", tool));`
没赋回 `spec`，条件被静默丢弃。

```java
// 模块说明：审计日志查询服务。只做「按会话/工具过滤 + 倒序分页 + 字段名转 snake_case」三件事。
package com.example.backendjava.service.impl;

// 项目内：limit 的默认值与上限契约表（与 Python 侧 app/core/limits.py 一一对应）
import com.example.backendjava.common.PageLimits;
// 项目内：审计日志实体（一行 = 一次工具调用）
import com.example.backendjava.entity.AuditLog;
// 项目内：审计日志仓库，支持按 Specification 动态拼条件
import com.example.backendjava.repository.AuditLogRepository;
// 项目内：审计业务接口（本类实现它）
import com.example.backendjava.service.AuditService;

// Jakarta 依赖注入注解：按类型注入字段，与项目现有写法保持一致
import jakarta.annotation.Resource;
// Spring Data：分页请求（页码 + 每页条数 + 排序）
import org.springframework.data.domain.PageRequest;
// Spring Data：分页参数接口，findAll(spec, pageable) 的形参类型
import org.springframework.data.domain.Pageable;
// Spring Data：排序规则，审计列表固定按 id 倒序（最新的在最前）
import org.springframework.data.domain.Sort;
// Spring Data：JPA 条件表达式，用来按 session_id / tool 动态过滤
import org.springframework.data.jpa.domain.Specification;
// Spring：把本类注册成 AuditService 的实现
import org.springframework.stereotype.Service;

// 标准库：LinkedHashMap 保证输出字段顺序稳定，便于对照接口文档
import java.util.LinkedHashMap;
// 标准库：List 返回审计行列表
import java.util.List;
// 标准库：Map 承载 snake_case 字典
import java.util.Map;

/**
 * 审计日志查询服务实现。
 *
 * <p><b>易错点：</b>{@link Specification#and} 返回的是<b>新对象</b>，不会修改原对象；
 * 拼条件时必须把返回值赋回变量，否则条件会被静默丢弃——这正是旧代码「按工具筛选无效」的原因。</p>
 */
@Service
public class AuditServiceImpl implements AuditService {

    /** 审计日志仓库：列表查询走它。 */
    @Resource
    private AuditLogRepository auditLogRepository;

    /**
     * 查询审计日志：支持按会话与工具过滤，按 id 倒序分页。
     *
     * @param sessionId 会话 id；null 或空白表示不过滤
     * @param tool      工具名；null 或空白表示不过滤
     * @param limit     最多返回多少条（内部会再夹一次上限）
     * @return snake_case 的审计行列表，最新的在最前
     */
    @Override
    public List<Map<String, Object>> list(String sessionId, String tool, int limit) {
        // 分页与过滤都在数据库侧完成，避免把整表加载进内存
        // limit 的上限由 controller 的 @Max 拦过，这里再夹一次是给「内部直接调用」兜底
        Pageable pageable = PageRequest.of(0, PageLimits.clamp(limit, PageLimits.MAX_AUDIT),
                Sort.by(Sort.Direction.DESC, "id"));

        // 从「无条件」开始往上叠：unrestricted() 等价于 WHERE 1=1
        Specification<AuditLog> spec = Specification.unrestricted();
        if (sessionId != null && !sessionId.isBlank()) {
            spec = spec.and(eq("sessionId", sessionId));
        }
        if (tool != null && !tool.isBlank()) {
            // 必须赋回 spec：and() 返回新对象，不赋回等于没加这个条件
            spec = spec.and(eq("tool", tool));
        }

        return auditLogRepository.findAll(spec, pageable).getContent().stream()
                .map(this::toMap)   // 字段名转成 snake_case，与前端对齐
                .toList();
    }

    /**
     * 构造一个 equal 谓词。
     *
     * @param column 实体属性名（不是数据库列名），如 sessionId / tool
     * @param value  要匹配的值
     * @return JPA 条件
     */
    private static Specification<AuditLog> eq(String column, Object value) {
        return (root, query, cb) -> cb.equal(root.get(column), value);
    }

    /**
     * 审计实体 → snake_case 字典（与前端审计页字段对齐）。
     *
     * @param row 审计实体
     * @return 字典
     */
    private Map<String, Object> toMap(AuditLog row) {
        Map<String, Object> map = new LinkedHashMap<>();
        map.put("id", row.getId());
        map.put("session_id", row.getSessionId());
        map.put("tool", row.getTool());
        map.put("arguments", row.getArguments());
        map.put("success", Boolean.TRUE.equals(row.getSuccess()));
        map.put("result", row.getResult());
        map.put("created_at", row.getCreatedAt());
        return map;
    }
}
```

## 2. 2.3 「测试连接」可用：字段别名 + 从密钥库取 Key

**② 用下面这段替换原有的 `ProbeRequest` record：**

```java
    /**
     * 模型连通性测试请求。
     *
     * <p>兼容两种字段名：新约定是 {@code provider_id}，旧前端发的是 {@code provider}，
     * 用 {@link JsonAlias} 让两个名字都能反序列化到同一个字段，前后端不必同时上线。</p>

            // API Key；仅用于本地调试，正常情况留空、由密钥库补齐

    }
```

### 2.2 `DefaultLlmService` 整文件替换

> **文件**：`backend_java/src/main/java/com/example/backendjava/service/impl/DefaultLlmService.java`
> **改动**：构造器多注入一个 `SecretStore`；`probe()` 的 Key 优先取密钥库。

```java
// 模块说明：模型服务的默认实现。完成供应商清单、模型构建与连通性测试。
package com.example.backendjava.service.impl;

// Spring 服务注解：把本类注册成 LlmService 的唯一实现
import org.springframework.stereotype.Service;
// 项目内业务异常：配置错误时抛出，由全局异常处理器转成 ApiResponse
import com.example.backendjava.common.ApiException;
// LangChain4j 同步模型接口
import dev.langchain4j.model.chat.ChatModel;
// LangChain4j 流式模型接口
import dev.langchain4j.model.chat.StreamingChatModel;
// 模型业务接口：供应商清单、连通性测试与模型装配
import com.example.backendjava.llm.LlmService;
// 模型工厂路由：按供应商 id 选择具体工厂
import com.example.backendjava.llm.LlmModelFactoryRouter;
// 供应商与模型清单的查询入口（内置 + 用户自定义）
import com.example.backendjava.llm.LlmProviderRegistry;
// 模型接口的供应商/模型/探测 DTO 容器
import com.example.backendjava.dto.LlmDtos;
// 装配一个模型实例所需的参数
import com.example.backendjava.dto.LlmModelSpec;
// 密钥仓库：从加密存储里取出用户在设置页保存的 API Key
import com.example.backendjava.settings.SecretStore;

// 标准库：List 用于供应商清单
import java.util.List;

/**
 * 模型服务默认实现。
 *
 * <p>它不依赖业务数据库，只依赖模型注册表、工厂路由器与密钥仓库，
 * 因此可以直接用来验证 Java 到模型供应商的连通性。</p>
 */
@Service
public class DefaultLlmService implements LlmService {

    /** 供应商与模型清单（内置 + 自定义端点）。 */
    private final LlmProviderRegistry registry;

    /** 模型工厂路由器：按 providerId 选择 OpenAI 兼容等具体实现。 */
    private final LlmModelFactoryRouter factoryRouter;

    /** 密钥仓库：用户在设置页保存的 Key 存这里，测试连接时直接复用。 */
    private final SecretStore secretStore;

    /**
     * 构造器注入。
     *
     * @param registry      模型注册表
     * @param factoryRouter 模型工厂路由器
     * @param secretStore   密钥仓库
     */
    public DefaultLlmService(LlmProviderRegistry registry,
                             LlmModelFactoryRouter factoryRouter,
                             SecretStore secretStore) {
        this.registry = registry;
        this.factoryRouter = factoryRouter;
        this.secretStore = secretStore;
    }

    /**
     * 返回全部供应商与模型。
     *
     * @return 供应商清单
     */
    @Override
    public LlmDtos.ProvidersResult listProviders() {
        return new LlmDtos.ProvidersResult(registry.listProviders());
    }

    /**
     * 发一次极小的请求，验证密钥、模型名与网络是否可用。
     *
     * <p>密钥取值顺序：<b>请求体显式传入（本地调试）</b> → <b>密钥库</b>。
     * 前端点「测试连接」时不会把明文 Key 再发一次，所以必须能读到密钥库。</p>
     *
     * @param request 测试参数
     * @return 结构化测试结果；不会抛出网络异常
     */
    @Override
    public LlmDtos.ProbeResult probe(LlmDtos.ProbeRequest request) {
        // 记录开始时间，用于计算耗时；使用纳秒避免短请求显示 0ms
        long startedNanos = System.nanoTime();
        try {
            // 供应商必须存在；不存在时直接 404（provider_id 为 null 也会走到这里，提示里带 null）
            LlmDtos.ProviderInfo provider = registry.findProvider(request.providerId())
                    .orElseThrow(() -> new ApiException(404, "未知的模型供应商：" + request.providerId()));

            // 解析模型：未指定模型名时取该供应商的默认模型
            LlmDtos.ModelInfo modelInfo = registry.resolveModel(request.providerId(), request.model());

            // 接口地址优先用请求里显式传入的，其次用注册表默认值
            String baseUrl = isBlank(request.baseUrl()) ? provider.baseUrl() : request.baseUrl();

            // 密钥：请求体 > 密钥库；只有本地调试才会把 Key 放进请求体
            String apiKey = isBlank(request.apiKey()) ? secretOf(provider) : request.apiKey().strip();
            if (provider.requiresKey() && isBlank(apiKey)) {
                throw new ApiException(400, "尚未配置 " + provider.label() + " 的 API 密钥，"
                        + "请到设置页的「模型」分区填写（对应设置项：" + provider.secretKey() + "）");
            }

            // 组装模型参数：温度固定 0，尽量让 ping 请求稳定
            LlmModelSpec spec = new LlmModelSpec(
                    request.providerId(),
                    modelInfo.model(),
                    apiKey,
                    baseUrl,
                    0.0,
                    null
            );

            // 真正发一次网络请求；只要没抛异常就认为连通
            ChatModel chatModel = factoryRouter.createChatModel(spec);
            chatModel.chat("ping");

            return new LlmDtos.ProbeResult(true, elapsedMillis(startedNanos), null, null);
        } catch (Exception exception) {
            // 配置类异常与网络类异常分开提示，方便用户判断是去填 Key 还是查网络
            String kind = classifyError(exception);
            return new LlmDtos.ProbeResult(
                    false,
                    elapsedMillis(startedNanos),
                    // 错误信息截断到 300 字，避免把整段堆栈或超长响应返回给前端
                    truncate(exception.getMessage(), 300),
                    kind
            );
        }
    }

    /**
     * 创建同步聊天模型。
     *
     * @param spec 模型装配参数
     * @return 同步模型
     */
    @Override
    public ChatModel createChatModel(LlmModelSpec spec) {
        return factoryRouter.createChatModel(spec);
    }

    /**
     * 创建流式聊天模型。
     *
     * @param spec 模型装配参数
     * @return 流式模型
     */
    @Override
    public StreamingChatModel createStreamingModel(LlmModelSpec spec) {
        return factoryRouter.createStreamingModel(spec);
    }

    /**
     * 从密钥库取出供应商的 API Key。
     *
     * @param provider 供应商描述（提供密钥在库里的名字）
     * @return 密钥；供应商不需要密钥、还没配置或读库失败时返回 null
     */
    private String secretOf(LlmDtos.ProviderInfo provider) {
        if (isBlank(provider.secretKey())) {
            return null;
        }
        try {
            return secretStore.getSecret(provider.secretKey()).orElse(null);
        } catch (RuntimeException e) {
            // 密钥库读失败按「没配置」处理：让上层给出「去设置页填写」的提示，而不是 500
            return null;
        }
    }

    /**
     * 把纳秒起点换算成毫秒耗时。
     *
     * @param startedNanos System.nanoTime() 的起始值
     * @return 毫秒数
     */
    private long elapsedMillis(long startedNanos) {
        return (System.nanoTime() - startedNanos) / 1_000_000;
    }

    /**
     * 粗判异常属于哪一类，供前端给出不同提示。
     *
     * @param exception 捕获到的异常
     * @return secret / model / network / unknown
     */
    private String classifyError(Exception exception) {
        // 业务异常本身已经带了明确语义，按 code 分类最可靠
        if (exception instanceof ApiException apiException) {
            if (apiException.getCode() == 400) {
                return "secret";
            }
            if (apiException.getCode() == 404) {
                return "model";
            }
        }

        // 其它异常只能靠关键字粗判；不同 SDK 的文案差异很大，这里只求够用
        String text = exception.getMessage() == null ? "" : exception.getMessage().toLowerCase();
        if (text.contains("api key") || text.contains("401") || text.contains("403")
                || text.contains("unauthorized") || text.contains("密钥")) {
            return "secret";
        }
        if (text.contains("model") || text.contains("404") || text.contains("模型")) {
            return "model";
        }
        if (text.contains("timeout") || text.contains("connect") || text.contains("network")) {
            return "network";
        }
        return "unknown";
    }

    /**
     * 判断字符串是否为空白。
     *
     * @param value 待判断字符串
     * @return null、空串、纯空白都返回 true
     */
    private boolean isBlank(String value) {
        return value == null || value.isBlank();
    }

    /**
     * 截断过长的错误信息。
     *
     * @param value     原始文本
     * @param maxLength 最大字符数
     * @return 截断后的文本；null 原样返回
     */
    private String truncate(String value, int maxLength) {
        if (value == null || value.length() <= maxLength) {
            return value;
        }
        return value.substring(0, maxLength);
    }
}
```

## 3. 2.2 自定义供应商接入注册表

> 现在 `LlmProviderRegistry` 只返回 5 家内置供应商，用户在设置页填的

### 3.1 先把 `llm.provider` 从 SELECT 改成 STRING

> **文件**：`backend_java/src/main/java/com/example/backendjava/settings/BuiltinSettings.java`
> **改法**：找到 `llm.provider` 那一行，整体替换。

**为什么必须改**：`SettingKind.SELECT` 在写入校验时会拒绝候选值以外的取值
（见 `SettingDefinition#checkRangeOf`），而自定义端点的 id 是运行期才知道的 `custom-xxx`，

```java
        // 先校验供应商，避免模型名恰好同名时误命中别的供应商

                .orElseThrow(() -> new ApiException(404, "未知的模型供应商：" + providerId));

        // 未指定模型名：取清单第一个作为默认模型

            if (provider.models().isEmpty()) {
                throw new ApiException(404, "供应商 " + providerId + " 还没有配置任何模型");
            }
            return provider.models().get(0);
        }

        // 指定了模型名：必须精确匹配，不能静默换成别的模型
        return provider.models().stream()
                .filter(model -> model.model().equals(modelName))
                .findFirst()
                .orElseThrow(() -> new ApiException(
                        404,
                        "供应商 " + providerId + " 下没有模型 " + modelName

    /**
     * 合并「内置供应商 + 设置里的自定义端点」，并把自定义模型并进各自的 models。
     *
     * @return 合并后的供应商清单

    private List<LlmDtos.ProviderInfo> mergedProviders() {

        List<LlmDtos.ProviderInfo> merged = new ArrayList<>(BUILTIN_PROVIDERS.size() + 4);

        // 1) 内置供应商：把 llm.custom_models 里归属它的模型并进去
        for (LlmDtos.ProviderInfo builtin : BUILTIN_PROVIDERS) {
            merged.add(mergeModels(builtin, customModels));

        // 2) 自定义端点：id 统一加 custom- 前缀
        for (Map<String, Object> item : settingItems("llm.custom_providers")) {
            String rawId = stringOf(item, "id");
            // 没有 id 就无法被 llm.provider 选中，直接忽略这一项
            if (rawId.isBlank()) {
                continue;

            String id = CUSTOM_PREFIX + rawId;
            // 重复 id 只保留第一条：后一条覆盖前一条会让用户以为「改了没生效」
            boolean duplicated = merged.stream().anyMatch(provider -> provider.id().equals(id));
            if (duplicated) {
                continue;
            }
            String baseUrl = stringOf(item, "base_url");
            // 没有地址就无法发请求；忽略这一项，而不是留一个注定失败的供应商
            if (baseUrl.isBlank()) {
                continue;
            }
            String label = stringOf(item, "label");
            if (label.isBlank()) {
                label = rawId;
            }
            List<LlmDtos.ModelInfo> models = new ArrayList<>();
            for (CustomModel model : customModels) {
                if (model.providerId().equals(id)) {
                    models.add(model.info());
                }
            }
            // 密钥名约定为 custom-xxx.api_key，与前端 ModelSection.vue 一致
            merged.add(new LlmDtos.ProviderInfo(
                    id, label, baseUrl, id + ".api_key", true, true, List.copyOf(models)));
        }
        return List.copyOf(merged);
    }

    /**
     * 把一个内置供应商与它的补充模型合并。
     *
     * @param builtin      内置供应商
     * @param customModels 设置里声明的全部自定义模型
     * @return 合并后的供应商；没有补充模型时原样返回
     */
    private LlmDtos.ProviderInfo mergeModels(LlmDtos.ProviderInfo builtin, List<CustomModel> customModels) {
        List<LlmDtos.ModelInfo> extra = new ArrayList<>();
        for (CustomModel model : customModels) {
            if (model.providerId().equals(builtin.id())) {
                extra.add(model.info());
            }
        }
        // 没有补充模型：直接返回原对象，避免无意义地重建
        if (extra.isEmpty()) {
            return builtin;
        }
        Map<String, LlmDtos.ModelInfo> byName = new LinkedHashMap<>();
        for (LlmDtos.ModelInfo info : builtin.models()) {
            byName.put(info.model(), info);
        }
        // 同名模型以用户填的为准：context_window / 单价应该听用户的
        for (LlmDtos.ModelInfo info : extra) {
            byName.put(info.model(), info);
        }
        return new LlmDtos.ProviderInfo(
                builtin.id(), builtin.label(), builtin.baseUrl(), builtin.secretKey(),
                builtin.requiresKey(), builtin.isCustom(), List.copyOf(byName.values()));
    }

    /**
     * 读取设置项 llm.custom_models，转成「供应商 id + 模型描述」的列表。
     *
     * @return 自定义模型列表；设置读失败或格式不对时返回空列表
     */
    private List<CustomModel> readCustomModels() {
        List<CustomModel> result = new ArrayList<>();
        for (Map<String, Object> item : settingItems("llm.custom_models")) {
            String provider = stringOf(item, "provider");
            String model = stringOf(item, "model");
            // context_window 必填：没有它就不知道该在什么时候压缩上下文，宁可忽略这一项
            int contextWindow = intOf(item, "context_window", 0);
            if (provider.isBlank() || model.isBlank() || contextWindow <= 0) {
                continue;
            }
            String label = stringOf(item, "label");
            if (label.isBlank()) {
                label = model;
            }
            result.add(new CustomModel(
                    normalizeProviderId(provider),
                    new LlmDtos.ModelInfo(
                            model,
                            label,
                            contextWindow,
                            boolOf(item, "supports_tools", true),
                            boolOf(item, "supports_vision", false),
                            doubleOf(item, "price_in", 0.0),
                            doubleOf(item, "price_out", 0.0))));
        }
        return result;
    }

    /**
     * 归一化 custom_models 里写的 provider 字段。
     *
     * <p>用户可能写内置 id（deepseek），也可能写自定义端点的裸 id（myapi）；
     * 这里统一成「内置保持原名、其余补 custom- 前缀」，避免同一家供应商出现两个 id。</p>
     *
     * @param raw 用户填的 provider
     * @return 归一化后的供应商 id
     */
    private static String normalizeProviderId(String raw) {
        if (raw.startsWith(CUSTOM_PREFIX)) {
            return raw;
        }
        boolean builtin = BUILTIN_PROVIDERS.stream().anyMatch(provider -> provider.id().equals(raw));
        return builtin ? raw : CUSTOM_PREFIX + raw;
    }

    /**
     * 读取一个 JSON 数组型设置项，并统一成 {@code List<Map<String, Object>>}。
     *
     * @param key 设置键，如 llm.custom_providers
     * @return 数组里的对象项；不是数组或读失败时返回空列表
     */
    private List<Map<String, Object>> settingItems(String key) {
        Object value;
        try {
            value = settingsRegistry.getSetting(key);
        } catch (RuntimeException e) {
            // 读设置失败按「没有自定义项」处理：绝不能因为一次读库失败让整个对话 500
            return List.of();
        }
        if (!(value instanceof List<?> list)) {
            return List.of();
        }
        List<Map<String, Object>> items = new ArrayList<>(list.size());
        for (Object element : list) {
            if (element instanceof Map<?, ?> map) {
                Map<String, Object> normalized = new LinkedHashMap<>();
                map.forEach((itemKey, itemValue) -> normalized.put(String.valueOf(itemKey), itemValue));
                items.add(normalized);
            }
        }
        return items;
    }

    /**
     * 读一个字符串字段。
     *
     * @param item JSON 对象
     * @param key  字段名
     * @return 去首尾空白后的字符串；缺失时为空串
     */
    private static String stringOf(Map<String, Object> item, String key) {
        Object value = item.get(key);
        return value == null ? "" : String.valueOf(value).strip();
    }

    /**
     * 读一个整数字段。
     *
     * @param item     JSON 对象
     * @param key      字段名
     * @param fallback 缺失或类型不对时的兜底值
     * @return 整数值
     */
    private static int intOf(Map<String, Object> item, String key, int fallback) {
        Object value = item.get(key);
        return value instanceof Number number ? number.intValue() : fallback;
    }

    /**
     * 读一个浮点字段。
     *
     * @param item     JSON 对象
     * @param key      字段名
     * @param fallback 缺失或类型不对时的兜底值
     * @return 浮点值
     */
    private static double doubleOf(Map<String, Object> item, String key, double fallback) {
        Object value = item.get(key);
        return value instanceof Number number ? number.doubleValue() : fallback;
    }

    /**
     * 读一个布尔字段。
     *
     * @param item     JSON 对象
     * @param key      字段名
     * @param fallback 缺失或类型不对时的兜底值
     * @return 布尔值
     */
    private static boolean boolOf(Map<String, Object> item, String key, boolean fallback) {
        Object value = item.get(key);
        return value instanceof Boolean flag ? flag : fallback;
    }

    /**
     * 一条自定义模型的归属信息。
     *
     * @param providerId 归一化后的供应商 id（内置原名或 custom-xxx）
     * @param info       模型静态描述（模型名、窗口、单价等）
     */
    private record CustomModel(
            // 归一化后的供应商 id
            String providerId,
            // 模型静态描述
            LlmDtos.ModelInfo info
    ) {
    }
}
```

### 4.4 `ChatServiceImpl#usage()` 改成按会话 + 按模型聚合

> **文件**：`backend_java/src/main/java/com/example/backendjava/service/impl/ChatServiceImpl.java`
> **改法**：用下面两个方法替换现有的 `usage()`；`ModelAccumulator` 与 `round4` 直接追加到类尾部。

```java
    /**
     * 读取会话级用量汇总：总 token、总费用，并按模型拆分。
     *
     * <p>数据来源是助手消息上的四个用量列；用户消息与 doc 模式里未调用模型的轮次不计入 token，
     * 但轮次数仍然按助手消息条数统计（与旧行为保持一致）。</p>
     *
     * @param sessionId 会话 id
     * @return 用量汇总
     */
    @Override
    public ChatDtos.SessionUsage usage(String sessionId) {
        List<ChatMessage> rows = chatPersistence.findMessages(sessionId);
        // 按模型聚合：LinkedHashMap 保留「第一次出现」的顺序，面板看起来更稳定
        Map<String, ModelAccumulator> byModel = new LinkedHashMap<>();
        long turns = 0L;
        long inputTotal = 0L;
        long outputTotal = 0L;
        double costTotal = 0.0;

        for (ChatMessage row : rows) {
            // 只有助手消息带用量；用户消息直接跳过
            if (!"assistant".equals(row.getRole())) {
                continue;
            }
            turns++;
            long input = row.getInputTokens() == null ? 0L : row.getInputTokens();
            long output = row.getOutputTokens() == null ? 0L : row.getOutputTokens();
            double cost = row.getCost() == null ? 0.0 : row.getCost();

            inputTotal += input;
            outputTotal += output;
            costTotal += cost;

            // 早期数据 / doc 模式没有模型名：归到 unknown，前端照样能展示
            String model = (row.getModel() == null || row.getModel().isBlank())
                    ? "unknown"
                    : row.getModel();
            byModel.computeIfAbsent(model, ignored -> new ModelAccumulator()).add(input + output, cost);
        }

        List<ChatDtos.ModelUsage> perModel = new ArrayList<>(byModel.size());
        for (Map.Entry<String, ModelAccumulator> entry : byModel.entrySet()) {
            ModelAccumulator accumulator = entry.getValue();
            perModel.add(new ChatDtos.ModelUsage(
                    entry.getKey(), accumulator.turns, accumulator.tokens, round4(accumulator.cost)));
        }

        return new ChatDtos.SessionUsage(
                sessionId,
                turns,
                inputTotal,
                outputTotal,
                inputTotal + outputTotal,
                round4(costTotal),
                "CNY",
                perModel);
    }

    /**
     * 按模型聚合用量的小累加器（只在本类的 {@code usage()} 里使用）。
     */
    private static final class ModelAccumulator {

        /** 该模型的助手消息条数（= 轮次）。 */
        private long turns;

        /** 该模型累计 token（input + output）。 */
        private long tokens;

        /** 该模型累计费用（元）。 */
        private double cost;

        /**
         * 累加一轮。
         *
         * @param turnTokens 本轮 token（input + output）
         * @param turnCost   本轮费用（元）
         */
        void add(long turnTokens, double turnCost) {
            turns++;
            tokens += turnTokens;
            cost += turnCost;
        }
    }

    /**
     * 保留四位小数，避免浮点误差在用量面板里显示成 0.30000000000000004。
     *
     * @param value 原始值
     * @return 四舍五入到四位小数
     */
    private static double round4(double value) {
        return Math.round(value * 10_000.0) / 10_000.0;
    }
```

### 5.1 `AgentEventConfig` 加一个「记忆抽取」线程池

> **文件**：`backend_java/src/main/java/com/example/backendjava/config/AgentEventConfig.java`
> **改法**：在 `chatTurnExecutor()` 方法后面追加这个 Bean。

**为什么单独开一个池**：记忆抽取是一次额外的模型调用，可能跑十几秒。
如果丢进 `chatTurnExecutor`，用户下一次发消息时会和抽取抢线程，表现为「发出去半天没反应」。

```java
    /**
     * 记忆抽取线程池（单线程）。
     *
     * <p>为什么单独开：记忆抽取是一次额外的模型调用，慢且可以失败；
     * 如果和 {@link #chatTurnExecutor()} 混用，会跟下一轮对话抢线程，让用户感觉「发消息没反应」。
     * 单线程足够——抽取本来就该排在对话后面，不急着并行。</p>
     *
     * @return 单线程池；Bean 名 memoryExtractExecutor 供 {@code @Resource} 按名注入
     */
    @Bean(destroyMethod = "shutdown")
    public ExecutorService memoryExtractExecutor() {
        AtomicInteger counter = new AtomicInteger(1);
        ThreadFactory factory = runnable -> {
            Thread thread = new Thread(runnable, "memory-extract-" + counter.getAndIncrement());
            // 守护线程：应用关闭时不阻塞 JVM 退出
            thread.setDaemon(true);
            return thread;
        };
        return Executors.newSingleThreadExecutor(factory);
    }
```

> `@Resource` 是按 **Bean 名** 注入的，所以 `ChatServiceImpl` 里
> `@Resource private ExecutorService chatTurnExecutor;` 与新加的
> `@Resource private ExecutorService memoryExtractExecutor;` 不会互相抢注入。

### 5.4 整段替换 `runTurn(...)`

> 用下面的方法体替换现有的 `runTurn`（约 274–346 行）。

```java
    /**
     * 真正执行一轮对话：补种上下文 → 落用户消息 → （doc 模式分支）→ 装配模型 → 跑工具循环 → 落库收尾。
     *
     * <p>本方法运行在 chatTurnExecutor 线程上，允许长时间阻塞（包括等待用户确认）。</p>
     *
     * @param sessionId 会话 id
     * @param request   归一化后的请求
     * @param recorder  本轮记录器
     */
    private void runTurn(String sessionId, ChatDtos.ChatRequest request, TurnRecorder recorder) {
        long startedAt = System.currentTimeMillis();
        // 本轮轮次 id：轨迹落库用它把同一轮的事件串起来
        String turnId = cn.hutool.core.util.IdUtil.fastSimpleUUID();
        traceEventSink.setTurnId(turnId);

        try {
            // 1) thinking：让用户立刻看到「我在动」，而不是盯着空屏幕
            sessionBus.emit(sessionId, chatEvents.thinking(sessionId, "start", 0, 0, "正在准备对话…"));

            // 2) 先读历史（此时还不含本轮用户消息），必要时压缩；历史会真正进入模型请求
            SeedContext seed = buildSeedContext(sessionId);
            sessionBus.emit(sessionId, chatEvents.thinking(sessionId, "history",
                    System.currentTimeMillis() - startedAt, seed.recent().size(),
                    "已载入 " + seed.recent().size() + " 条历史消息"));

            // 3) 落用户消息（先落库，避免崩溃时丢失用户输入）
            persistMessage(sessionId, "user", request.message(), request.mode());

            // 3.1) doc 模式：解析 `\doc` 子命令，确定性分支不进模型工具循环
            if ("doc".equals(request.mode())) {
                String answer = executeDocCommand(request);
                recorder.appendAnswer(answer);
                // 一次性发给前端：doc 命令要么是即时结果，要么是同步问答，不需要逐字流
                sessionBus.emit(sessionId, chatEvents.token(answer));
                // 直接返回，finally 里统一 finishTurn（落库 + done + 关流）
                return;
            }

            // 4) 建模型（供应商/模型名/密钥都在 buildModelSpec 里）
            LlmModelSpec spec = buildModelSpec();
            StreamingChatModel chatModel = llmModelFactoryRouter.createStreamingModel(spec);
            recorder.setModel(spec.model());

            // 5) 组装工具表：每个工具包一层 ChatToolExecutor，事件就有了
            Map<ToolSpecification, ToolExecutor> tools = buildEventedToolMap(sessionId, recorder);

            // 6) 建 AiServices：
            //    - systemMessage 每轮现拼（记忆 / 技能 / 摘要），不写进记忆，避免被窗口挤掉；
            //    - chatMemory 负责把历史（以及本轮用户消息）真正带给模型。
            Assistant assistant = AiServices.builder(Assistant.class)
                    .streamingChatModel(chatModel)
                    .systemMessage(buildSystemMessage(seed, request.message()))
                    .chatMemory(buildChatMemory(seed.recent()))
                    .tools(tools)
                    .maxToolCallingRoundTrips(request.maxIterations())
                    .build();

            sessionBus.emit(sessionId, chatEvents.thinking(sessionId, "model",
                    System.currentTimeMillis() - startedAt, seed.recent().size(), "正在请求模型…"));

            // 7) 开本轮预算：工具边界会读它判断是否越线
            toolBudgetRegistry.startBudget(sessionId);

            // 8) 跑起来。start() 是阻塞的，直到整轮结束（含所有工具调用）
            assistant.chat(request.message())
                    .onPartialResponse(partial -> {
                        // 用户点了停止：不再转发增量，但模型那边没法取消，让它自己跑完
                        if (recorder.isStopped()) {
                            return;
                        }
                        recorder.appendAnswer(partial);
                        sessionBus.emit(sessionId, chatEvents.token(partial));
                    })
                    .onCompleteResponse(response -> recordUsage(sessionId, recorder, response))
                    .onError(error -> sessionBus.emit(sessionId,
                            chatEvents.error("模型调用失败：" + error.getMessage(),
                                    request.debug() ? stackOf(error) : null)))
                    .start();

        } catch (RuntimeException ex) {
            // 任何未预料异常都要变成 error 事件，否则前端只能干等到超时
            sessionBus.emit(sessionId, chatEvents.error(
                    "本轮对话失败：" + ex.getMessage(), request.debug() ? stackOf(ex) : null));
        } finally {
            // 9) 落助手消息 + 发 done + 关流。无论成功失败都要走到这里
            finishTurn(sessionId, request, recorder, turnId);
        }
    }
```

### 5.5 整段替换 `finishTurn(...)`

> 用下面的方法体替换现有的 `finishTurn`（约 357–390 行）。

```java
    /**
     * 收尾：落库（含用量与工具轨迹）、发 done（或 stopped）、关流、清理运行时状态、异步抽取记忆。
     *
     * @param sessionId 会话 id
     * @param request   请求
     * @param recorder  本轮记录器
     * @param turnId    轮次 id
     */
    private void finishTurn(String sessionId, ChatDtos.ChatRequest request, TurnRecorder recorder, String turnId) {
        String answer = recorder.answer();
        try {
            // 1) 助手消息落库：正文 + 模式 + 工具轨迹 + 用量 + 模型名，历史回放与用量面板都靠它
            if (!answer.isBlank()) {
                Map<String, Object> usage = recorder.usage();
                chatPersistence.saveAssistantMessage(
                        sessionId,
                        answer,
                        request.mode(),
                        toolCallsJson(recorder.toolCalls()),
                        recorder.isStopped() ? "stopped" : "done",
                        recorder.elapsedMs() / 1000.0,
                        recorder.model(),
                        longOf(usage, "input_tokens"),
                        longOf(usage, "output_tokens"),
                        doubleOf(usage, "cost"));
            }
            // 2) 更新会话的 updated_at 与标题（首轮用第一句话当标题）
            touchSession(sessionId, request.message());
        } catch (RuntimeException ex) {
            // 落库失败不影响用户看到答案：只记日志
            log.warn("会话落库失败 sessionId={} turnId={}", sessionId, turnId, ex);
        }

        // 3) 用户点了停止 → 发 stopped；否则发 done
        if (recorder.isStopped()) {
            sessionBus.emit(sessionId, chatEvents.stopped(sessionId, answer, "user_stop"));
        } else {
            sessionBus.emit(sessionId, chatEvents.done(
                    sessionId,
                    answer,
                    recorder.elapsedMs(),
                    recorder.toolCalls(),
                    countMessages(sessionId),
                    recorder.files(),
                    recorder.usage(),
                    recorder.steerCount(),
                    recorder.model()));
        }
        // 4) 关流并清理：前端收到 done 后会把 loading 关掉
        sessionBus.finish(sessionId);
        // 5) 清掉本轮预算：下一轮会重新 startBudget，留着旧数据只会误判
        toolBudgetRegistry.clearBudget(sessionId);
        // 6) 清掉本线程的轮次 id：线程池复用线程，不清会把下一轮的轨迹记到本轮名下
        traceEventSink.clearTurnId();
        // 7) 异步抽取记忆：失败只记日志，绝不影响本轮对话
        scheduleMemoryExtraction(sessionId);
    }
```

### 5.8 追加到类尾部的私有方法

> 全部加到类的最末尾（`sessionTitle(...)` 之后、类的右大括号之前）。
> 这些方法合起来实现「补种 → 压缩 → 注入 → 记录用量 → 异步抽取」。

```java
    // ------------------------------------------------------------------ //
    // 上下文补种与压缩（2.1 / 2.4）
    // ------------------------------------------------------------------ //

    /**
     * 读取本会话历史并准备成「可以直接喂给模型」的形态：最近 N 条原文 + 更早内容的摘要。
     *
     * <p>压缩触发条件（三条同时满足）：{@code context.auto_compress=true}、
     * 估算 token 超过 {@code maxMessages × compress_threshold}、历史条数大于 {@code keep_recent_n}。</p>
     *
     * @param sessionId 会话 id
     * @return 补种上下文（最近消息 + 摘要，摘要可能为空串）
     */
    private SeedContext buildSeedContext(String sessionId) {
        List<ChatMessage> recent = new ArrayList<>(
                chatPersistence.findRecentMessages(sessionId, MAX_SEED_MESSAGES));

        int keepRecent = intSetting("context.keep_recent_n", 10);
        // 历史本来就不多：原样带上，顺便把之前压过的摘要继续带着
        if (recent.size() <= keepRecent || !boolSetting("context.auto_compress", true)) {
            return new SeedContext(recent, cachedSummary(sessionId));
        }

        int contextWindow = resolveContextWindow();
        double threshold = doubleSetting("context.compress_threshold", 0.7);
        long estimated = 0L;
        for (ChatMessage row : recent) {
            estimated += estimateTokens(row.getContent());
        }
        // 没到阈值：全部原样带上（此时仍在窗口内，压缩反而损失信息）
        if (estimated <= (long) (contextWindow * threshold)) {
            return new SeedContext(recent, cachedSummary(sessionId));
        }

        // 触发了：最近 keepRecent 条原样保留，更早的压成一段摘要
        int splitAt = recent.size() - keepRecent;
        List<ChatMessage> older = new ArrayList<>(recent.subList(0, splitAt));
        List<ChatMessage> tail = new ArrayList<>(recent.subList(splitAt, recent.size()));
        String summary = summarize(sessionId, older);

        log.info("上下文压缩：session={} 估算 {} token > 窗口 {} 的 {}%，保留最近 {} 条，摘要 {} 字",
                sessionId, estimated, contextWindow, threshold, tail.size(), summary.length());
        return new SeedContext(tail, summary);
    }

    /**
     * 把一段较早的历史压成摘要；同一批消息只摘要一次。
     *
     * @param sessionId 会话 id（摘要缓存按它分组）
     * @param older     需要压缩的较早消息（时间正序）
     * @return 摘要文本；失败时返回上一次的摘要（可能为空串）
     */
    private String summarize(String sessionId, List<ChatMessage> older) {
        if (older.isEmpty()) {
            return cachedSummary(sessionId);
        }
        long lastMessageId = idOf(older.get(older.size() - 1));
        SummaryCache cached = summaryCache.get(sessionId);
        // 同一批消息已经摘要过：直接复用，省一次模型调用
        if (cached != null && cached.lastMessageId() == lastMessageId) {
            return cached.summary();
        }
        String previous = cached == null ? "" : cached.summary();

        String summary;
        try {
            ChatModel chatModel = llmModelFactoryRouter.createChatModel(buildModelSpec());
            summary = chatModel.chat(buildSummaryPrompt(previous, older));
        } catch (RuntimeException e) {
            // 摘要失败不能打断对话：退回「只保留最近 N 条」，模型至少还能看到最近的上下文
            log.warn("上下文摘要失败，本轮退回「只保留最近 N 条」 session={}：{}", sessionId, e.getMessage());
            return previous;
        }
        if (summary == null || summary.isBlank()) {
            return previous;
        }
        String trimmed = summary.strip();
        if (trimmed.length() > MAX_SUMMARY_CHARS) {
            trimmed = trimmed.substring(0, MAX_SUMMARY_CHARS);
        }
        summaryCache.put(sessionId, new SummaryCache(lastMessageId, trimmed));
        return trimmed;
    }

    /**
     * 拼摘要提示词。
     *
     * @param previous 上一次的摘要（可能为空串）；要求模型合并进来，避免「压一次丢一段」
     * @param older    需要压缩的消息（时间正序）
     * @return 提示词
     */
    private String buildSummaryPrompt(String previous, List<ChatMessage> older) {
        StringBuilder prompt = new StringBuilder();
        prompt.append("你在帮一个对话系统压缩上下文。请把下面的历史对话压成一段摘要，")
                .append("保留：用户的目标与偏好、已经确认的结论、未完成的事项、关键文件路径与命令。")
                .append("不要编造，不要输出客套话，直接给摘要正文，控制在 ")
                .append(MAX_SUMMARY_CHARS).append(" 字以内。\n\n");
        if (previous != null && !previous.isBlank()) {
            prompt.append("已有的更早摘要（请合并进来，不要丢掉里面的事实）：\n")
                    .append(previous).append("\n\n");
        }
        prompt.append("需要压缩的对话片段：\n");
        int used = 0;
        for (ChatMessage row : older) {
            if (used >= MAX_SUMMARY_INPUT_CHARS) {
                prompt.append("…（更早的内容已省略）\n");
                break;
            }
            String text = nvl(row.getContent());
            int budget = MAX_SUMMARY_INPUT_CHARS - used;
            if (text.length() > budget) {
                text = text.substring(0, budget);
            }
            prompt.append("user".equals(row.getRole()) ? "用户：" : "助手：")
                    .append(text).append('\n');
            used += text.length();
        }
        return prompt.toString();
    }

    /**
     * 把最近的消息还原成 LangChain4j 的记忆。
     *
     * <p><b>为什么每轮新建：</b>记忆只服务于「这一次请求」。新建一个窗口记忆、把历史灌进去，
     * 请求结束即丢弃，既不会跨会话串味，也不用处理「多线程同时改同一个 memory」的问题。</p>
     *
     * @param recent 最近的消息（时间正序，不含本轮用户消息）
     * @return 已灌好历史的窗口记忆
     */
    private ChatMemory buildChatMemory(List<ChatMessage> recent) {
        ChatMemory memory = MessageWindowChatMemory.builder()
                .maxMessages(MAX_SEED_MESSAGES)
                .build();
        for (ChatMessage row : recent) {
            String text = nvl(row.getContent());
            if (text.isBlank()) {
                continue;
            }
            if ("user".equals(row.getRole())) {
                memory.add(UserMessage.from(text));
            } else if ("assistant".equals(row.getRole())) {
                memory.add(AiMessage.from(text));
            }
            // system / tool 行不补：它们不是对话轮次，塞进窗口只会挤掉真正的上下文
        }
        return memory;
    }

    /**
     * 读会话级摘要缓存。
     *
     * @param sessionId 会话 id
     * @return 摘要；没有压缩过时为空的字符串（调用方不需要判空）
     */
    private String cachedSummary(String sessionId) {
        SummaryCache cached = summaryCache.get(sessionId);
        return cached == null ? "" : cached.summary();
    }

    // ------------------------------------------------------------------ //
    // 系统提示词动态拼装（2.6）
    // ------------------------------------------------------------------ //

    /**
     * 拼本轮的完整系统提示词：基础模板 + 工作区记忆（仅首轮）+ 可用技能 + 更早内容的摘要。
     *
     * <p>这些内容都放在 systemMessage 而不是 chatMemory 里：systemMessage 每轮现拼、不占历史窗口，
     * 也不会因为窗口滑动被挤掉。</p>
     *
     * @param seed        补种上下文
     * @param userMessage 本轮用户输入（用来检索相关记忆）
     * @return 完整的系统提示词
     */
    private String buildSystemMessage(SeedContext seed, String userMessage) {
        StringBuilder system = new StringBuilder(systemPrompt);
        // 记忆只在新对话的第一条消息注入：这是设置项 memory.inject_enabled 声明的语义
        appendMemoryBlock(system, userMessage, seed.recent().isEmpty());
        appendSkillBlock(system);
        if (!seed.summary().isBlank()) {
            system.append("\n\n## 本会话更早内容的摘要（系统自动压缩，供你回忆）\n\n")
                    .append(seed.summary());
        }
        return system.toString();
    }

    /**
     * 追加「工作区记忆」段落（受 memory.enabled / memory.inject_enabled 控制）。
     *
     * @param system    正在拼装的系统提示词
     * @param query     检索关键词（本轮用户输入）
     * @param firstTurn 是否为新对话的第一条消息
     */
    private void appendMemoryBlock(StringBuilder system, String query, boolean firstTurn) {
        // 只有首轮注入；后续轮次模型已经能从历史里看到这些记忆
        if (!firstTurn || query == null || query.isBlank()) {
            return;
        }
        if (!boolSetting("memory.enabled", true) || !boolSetting("memory.inject_enabled", true)) {
            return;
        }
        int topK = intSetting("memory.top_k", 5);
        int minImportance = intSetting("memory.min_importance", 1);

        List<String> lines = new ArrayList<>();
        try {
            Map<String, Object> result = memoryService.search(
                    new MemoryDtos.MemorySearchRequest(null, query, topK));
            Object rawHits = result.get("hits");
            if (!(rawHits instanceof List<?> hits)) {
                return;
            }
            for (Object element : hits) {
                if (!(element instanceof Map<?, ?> hit)) {
                    continue;
                }
                // 重要度不达标的记忆不注入：低价值记忆只会干扰模型
                // hit 是 Map<?, ?>，不能直接传 longOf(Map<String,Object>)，这里就地取值
                long importance = hit.get("importance") instanceof Number number
                        ? number.longValue()
                        : 0L;
                if (importance < minImportance) {
                    continue;
                }
                String content = stringOf(hit, "content");
                if (content.isBlank()) {
                    continue;
                }
                String category = stringOf(hit, "category");
                lines.add("- [" + (category.isBlank() ? "fact" : category) + "] " + content);
            }
        } catch (RuntimeException e) {
            // 记忆检索失败按「没有记忆」处理：这是增强能力，不能拖垮主流程
            log.warn("记忆注入失败，本轮按无记忆处理：{}", e.getMessage());
            return;
        }
        if (lines.isEmpty()) {
            return;
        }
        system.append("\n\n## 工作区记忆（用户此前确认过的偏好与事实，可直接引用）\n\n")
                .append(String.join("\n", lines));
    }

    /**
     * 追加「可用技能」段落（受 skill.enabled / skill.auto_inject 控制）。
     *
     * <p>只放「技能名 + 一行描述」，完整正文仍由模型用 {@code read_skill} 按需读取：
     * 几十个技能全文塞进来，提示词会直接爆掉。</p>
     *
     * @param system 正在拼装的系统提示词
     */
    private void appendSkillBlock(StringBuilder system) {
        if (!boolSetting("skill.enabled", true) || !boolSetting("skill.auto_inject", true)) {
            return;
        }
        List<String> lines = new ArrayList<>();
        try {
            Map<String, Object> snapshot = skillService.snapshot();
            Object rawSkills = snapshot.get("skills");
            if (!(rawSkills instanceof List<?> skills)) {
                return;
            }
            for (Object element : skills) {
                if (lines.size() >= MAX_INJECTED_SKILLS) {
                    break;
                }
                if (!(element instanceof Map<?, ?> skill)) {
                    continue;
                }
                // 被用户在设置里禁用的技能不提示：避免模型读到却调不动
                if (Boolean.FALSE.equals(skill.get("enabled"))) {
                    continue;
                }
                String name = stringOf(skill, "name");
                String description = stringOf(skill, "description");
                if (name.isBlank() || description.isBlank()) {
                    continue;
                }
                lines.add("- " + name + "：" + oneLine(description, MAX_SKILL_DESCRIPTION_CHARS));
            }
        } catch (RuntimeException e) {
            // 技能扫描失败按「没有技能」处理
            log.warn("技能注入失败，本轮按无技能处理：{}", e.getMessage());
            return;
        }
        if (lines.isEmpty()) {
            return;
        }
        system.append("\n\n## 可用技能（需要时先调用 read_skill 读取完整说明）\n\n")
                .append(String.join("\n", lines));
    }

    // ------------------------------------------------------------------ //
    // 用量记录与预算
    // ------------------------------------------------------------------ //

    /**
     * 记录一次模型调用的用量：写进本轮记录器（随 done 事件下发），并累加到预算熔断。
     *
     * @param sessionId 会话 id
     * @param recorder  本轮记录器
     * @param response  模型返回的完整响应（含 tokenUsage，可能为 null）
     */
    private void recordUsage(String sessionId, TurnRecorder recorder, ChatResponse response) {
        TokenUsage usage = response == null ? null : response.tokenUsage();
        long input = (usage == null || usage.inputTokenCount() == null) ? 0L : usage.inputTokenCount();
        long output = (usage == null || usage.outputTokenCount() == null) ? 0L : usage.outputTokenCount();

        // 单价来自模型清单；手写的新模型名查不到时按 0 计，费用显示 0 而不是报错
        LlmDtos.ModelInfo info = resolveModelInfo(recorder.model());
        double cost = (input * info.priceIn() + output * info.priceOut()) / 1_000_000.0;

        recorder.setUsage(Map.of(
                "input_tokens", input,
                "output_tokens", output,
                "total_tokens", input + output,
                "cost", round4(cost)));

        // 喂给预算熔断：下一次工具调用前它会据此判断是否越线
        toolBudgetRegistry.addUsage(sessionId, input, output, info.priceIn(), info.priceOut());
    }

    /**
     * 异步抽取本轮记忆（受 memory.enabled / memory.extract_enabled 控制）。
     *
     * @param sessionId 会话 id
     */
    private void scheduleMemoryExtraction(String sessionId) {
        if (sessionId == null || sessionId.isBlank()) {
            return;
        }
        if (!boolSetting("memory.enabled", true) || !boolSetting("memory.extract_enabled", true)) {
            return;
        }
        memoryExtractExecutor.submit(() -> {
            try {
                memoryService.extract(new MemoryDtos.MemoryExtractRequest(sessionId, null));
            } catch (RuntimeException e) {
                // 抽取失败只记日志：它是一次「顺手」的额外调用，不能影响用户已经看到的回答
                log.warn("记忆抽取失败 sessionId={}：{}", sessionId, e.getMessage());
            }
        });
    }

    /**
     * 取当前供应商 id。
     *
     * @return 供应商 id；设置为空时按 deepseek 兜底
     */
    private String providerId() {
        Object value = settingsRegistry.getSetting("llm.provider");
        return (value == null || String.valueOf(value).isBlank()) ? "deepseek" : String.valueOf(value);
    }

    /**
     * 取当前设置的模型名。
     *
     * @return 模型名；设置为空时为空串（调用方再用供应商默认模型兜底）
     */
    private String currentModelName() {
        Object value = settingsRegistry.getSetting("llm.model");
        return value == null ? "" : String.valueOf(value).trim();
    }

    /**
     * 解析模型描述（窗口、单价）。查不到时返回一个「单价 0、窗口兜底」的描述。
     *
     * @param modelName 模型名；可为空
     * @return 模型描述；永不为 null
     */
    private LlmDtos.ModelInfo resolveModelInfo(String modelName) {
        String name = modelName == null ? "" : modelName;
        try {
            return llmProviderRegistry.resolveModel(providerId(), name);
        } catch (RuntimeException e) {
            // 手写的新模型名可能不在清单里：用量统计不该因此中断
            return new LlmDtos.ModelInfo(
                    name, name, DEFAULT_CONTEXT_WINDOW, true, false, 0.0, 0.0);
        }
    }

    /**
     * 取当前模型的上下文窗口。
     *
     * @return 窗口大小（token）；未知时返回兜底值
     */
    private int resolveContextWindow() {
        int window = resolveModelInfo(currentModelName()).contextWindow();
        return window > 0 ? window : DEFAULT_CONTEXT_WINDOW;
    }

    /**
     * 粗估一段文本占多少 token。
     *
     * @param text 文本
     * @return 估算 token 数（按 1 字符 ≈ 1 token）
     */
    private static int estimateTokens(String text) {
        if (text == null || text.isEmpty()) {
            return 0;
        }
        // 按「1 字符 ≈ 1 token」粗估：中文接近真实值，英文偏高。
        // 宁可早一点触发压缩，也不要等供应商报 context length 错误。
        return text.length();
    }

    /**
     * 取消息主键（null 视为 0）。
     *
     * @param row 消息实体
     * @return 主键
     */
    private static long idOf(ChatMessage row) {
        return row.getId() == null ? 0L : row.getId();
    }

    /**
     * 把文本压成一行并截断。
     *
     * @param text     原始文本
     * @param maxChars 最大字符数
     * @return 单行文本
     */
    private static String oneLine(String text, int maxChars) {
        String oneLine = nvl(text).replaceAll("\\s+", " ").strip();
        return oneLine.length() <= maxChars ? oneLine : oneLine.substring(0, maxChars) + "…";
    }

    /**
     * 空字符串安全访问：null 转成空串。
     *
     * @param text 文本
     * @return 非 null 的文本
     */
    private static String nvl(String text) {
        return text == null ? "" : text;
    }

    /**
     * 把工具轨迹序列化成 JSON；空轨迹返回 null（数据库里就不存 "[]"）。
     *
     * @param traces 工具轨迹
     * @return JSON 字符串或 null
     */
    private String toolCallsJson(List<ChatDtos.ToolCallTrace> traces) {
        if (traces == null || traces.isEmpty()) {
            return null;
        }
        try {
            return objectMapper.writeValueAsString(traces);
        } catch (Exception e) {
            // 序列化失败只丢轨迹，不能影响正文落库
            log.warn("工具轨迹序列化失败，本条消息不存轨迹：{}", e.getMessage());
            return null;
        }
    }

    /**

    /**

    /**
     * 从 Map 里读字符串（不存在时返回空串）。
     *
     * @param map 数据来源
     * @param key 字段名
     * @return 去首尾空白后的字符串
     */
    private static String stringOf(Map<?, ?> map, String key) {
        if (map == null) {
            return "";
        }
        Object value = map.get(key);
        return value == null ? "" : String.valueOf(value).strip();
```

```java
    /** `\doc -l` 最多列出多少篇文档；再多就建议用户去「知识库」页看。 */
    private static final int DOC_LIST_LIMIT = 50;

    /** `\doc` 后面什么都没写时的默认问题。 */
    private static final String DOC_DEFAULT_QUERY = "请概括这份文档的主要内容";

    /** 送进提示词的单个片段最大字符数。 */
    private static final int MAX_DOC_SNIPPET_CHARS = 1_200;

    /** 送进提示词的全部片段总字符上限，避免检索结果把窗口占满。 */
    private static final int MAX_DOC_CONTEXT_CHARS = 6_000;

    /** 识别 `\doc` 前缀：允许大小写混写，`.` 跨行匹配（用户可能粘贴多行内容）。 */
    private static final Pattern DOC_PREFIX =
            Pattern.compile("^\\\\doc\\b[ \\t]*(.*)$", Pattern.DOTALL | Pattern.CASE_INSENSITIVE);

    /** `\doc` 的帮助类动词。 */
    private static final Set<String> HELP_VERBS = Set.of("-h", "--help", "?", "？", "help");

    /** `\doc` 的列文档动词。 */
    private static final Set<String> LIST_VERBS = Set.of("-l", "--list", "-ls");

    /** `\doc` 的删除动词。 */
    private static final Set<String> DELETE_VERBS = Set.of("-d", "--delete", "-rm");

    /** `\doc` 的导入动词。 */
    private static final Set<String> IMPORT_VERBS = Set.of("-i", "--import", "-a", "--add");

    /** `\doc -h` 的完整用法文本；写入 Java 源码时反斜杠要写两遍（`\\doc`）。 */
    private static final String DOC_HELP_TEXT = """
            \\doc 知识库指令
              \\doc -h, --help, ?        显示本帮助
              \\doc -l, --list, -ls      列出已入库的文档（最多 50 篇）
              \\doc -d, --delete <名字>  按文档名或来源删除一篇文档
              \\doc -i, --import <路径>  把本地文件导入知识库（一次一个文件）
              \\doc <问题>               在知识库里检索并回答（片段数由请求里的 doc_top_k 决定）

            说明：
            - 名字可以只写一部分，按「完全匹配 → 包含匹配」的顺序找；
            - 不带 \\doc 前缀的消息仍按普通 Agent 对话处理。
            """;

    /**
     * 解析一条 `\doc` 指令。
     *
     * @param message 用户原始输入
     * @return 解析结果；永不为 null
     */
    private DocCommand parseDocCommand(String message) {
        String text = nvl(message).strip();
        Matcher matcher = DOC_PREFIX.matcher(text);
        // 没有 `\doc` 前缀：整句当作检索问题
        if (!matcher.matches()) {
            return new DocCommand("search", "", text);
        }
        String rest = matcher.group(1).strip();
        // 只写了 `\doc`：按「用户想看看怎么用」处理，直接回帮助
        if (rest.isEmpty()) {
            return new DocCommand("help", "", "");
        }
        String verb = rest.split("\\s+", 2)[0];
        String argument = rest.length() > verb.length()
                ? rest.substring(verb.length()).strip()
                : "";
        // 动词统一小写再比对，避免 `-L` / `-D` 之类因为大小写被当成问题
        String lower = verb.toLowerCase(Locale.ROOT);

        if (HELP_VERBS.contains(lower)) {
            return new DocCommand("help", "", "");
        }
        if (LIST_VERBS.contains(lower)) {
            return new DocCommand("list", "", "");
        }
        if (DELETE_VERBS.contains(lower)) {
            // 少了文件名：回 unknown，让 executeDocCommand 给出用法提示
            return argument.isEmpty()
                    ? new DocCommand("unknown", verb, "")
                    : new DocCommand("delete", argument, "");
        }
        if (IMPORT_VERBS.contains(lower)) {
            return argument.isEmpty()
                    ? new DocCommand("unknown", verb, "")
                    : new DocCommand("import", argument, "");
        }
        // 以 - 开头但不在任何命令表里：明确回「不认识」，不要当成问题去检索
        if (lower.startsWith("-")) {
            return new DocCommand("unknown", verb, argument);
        }
        // 其余情况：整段（含第一个词）都是问题
        return new DocCommand("search", "", rest);
    }

    /**
     * 执行一条 `\doc` 指令，返回要一次性推给前端的文本。
     *
     * @param request 本轮请求（用到 message / docTopK / mode）
     * @return 回答或提示文本；永不为 null
     */
    private String executeDocCommand(ChatDtos.ChatRequest request) {
        DocCommand command = parseDocCommand(request.message());
        return switch (command.action()) {
            case "help" -> DOC_HELP_TEXT;
            case "list" -> docList();
            case "delete" -> docDelete(command.target());
            case "import" -> docImport(command.target());
            case "unknown" -> "不认识的 \\doc 子命令：" + command.target() + "\n\n" + DOC_HELP_TEXT;
            case "search" -> docAnswer(command.query(), request.docTopK());
            // 理论上不会走到：动作集合是封闭的，兜底回帮助
            default -> DOC_HELP_TEXT;
        };
    }

    /**
     * `\doc -l`：列出已入库的文档。
     *
     * @return 文档清单文本
     */
    private String docList() {
        List<RagDtos.RagDocument> documents = ragService.listDocuments(DOC_LIST_LIMIT, 0);
        if (documents.isEmpty()) {
            return "知识库里还没有文档。用 `\\doc -i <文件路径>` 导入一份。";
        }
        StringBuilder text = new StringBuilder("知识库文档（最多显示 " + DOC_LIST_LIMIT + " 篇）：\n");
        for (RagDtos.RagDocument document : documents) {
            text.append("- #").append(document.id()).append(' ')
                    .append(docDisplayName(document))
                    .append("（").append(document.chunks()).append(" 个片段）\n");
        }
        text.append("\n删除用 `\\doc -d <名字>`，导入用 `\\doc -i <文件路径>`。");
        return text.toString();
    }

    /**
     * `\doc -d <名字>`：按名字删除一篇文档。
     *
     * @param target 用户写的文档名（允许只写一部分）
     * @return 操作结果文本
     */
    private String docDelete(String target) {
        RagDtos.RagDocument matched = findDoc(target);
        if (matched == null) {
            return "知识库里没有找到「" + target + "」。先发 `\\doc -l` 看看有哪些文档。";
        }
        ragService.deleteById(matched.id());
        return "已删除文档 #" + matched.id() + " " + docDisplayName(matched) + "。";
    }

    /**
     * `\doc -i <路径>`：把一个本地文件导入知识库。
     *
     * @param target 用户写的文件路径
     * @return 操作结果文本
     */
    private String docImport(String target) {
        Path path;
        try {
            path = Path.of(target).toAbsolutePath().normalize();
        } catch (RuntimeException e) {
            // 路径里有非法字符（例如 Windows 保留名）：给出可读提示而不是堆栈
            return "路径不合法：" + target;
        }
        if (!Files.exists(path)) {
            return "文件不存在：" + path;
        }
        if (Files.isDirectory(path)) {
            return "这是一个目录，不是文件：" + path + "\n一次只能导入一个文件，请指定目录里的具体文件。";
        }
        try {
            RagDtos.IndexResult result = ragService.indexFile(
                    new RagDtos.IndexFileRequest(path.toString(), path.toString(), null, false));
            return "已导入 " + path.getFileName() + "：动作 " + result.action()
                    + "，共 " + result.totalChunks() + " 个片段（本次新建 " + result.newChunks() + " 个）。";
        } catch (RuntimeException e) {
            return "导入失败：" + e.getMessage();
        }
    }

    /**
     * `\doc <问题>`：先检索，再让模型只依据检索结果回答。
     *
     * @param query 用户问题
     * @param topK  片段数上限（来自请求的 doc_top_k）
     * @return 回答文本；模型不可用时退回「直接给命中片段」
     */
    private String docAnswer(String query, int topK) {
        String question = nvl(query).strip();
        if (question.isEmpty()) {
            question = DOC_DEFAULT_QUERY;
        }

        List<RagDtos.SearchHit> hits;
        try {
            int safeTopK = Math.max(1, Math.min(20, topK));
            hits = ragService.search(new RagDtos.SearchRequest(
                    question, safeTopK, null, null, null));
        } catch (RuntimeException e) {
            return "检索失败：" + e.getMessage();
        }
        if (hits.isEmpty()) {
            return "知识库里没有找到与「" + question + "」相关的内容。可以先发 `\\doc -l` 看看有哪些文档。";
        }

        StringBuilder context = new StringBuilder();
        int used = 0;
        for (RagDtos.SearchHit hit : hits) {
            if (used >= MAX_DOC_CONTEXT_CHARS) {
                break;
            }
            String text = nvl(hit.text());
            if (text.length() > MAX_DOC_SNIPPET_CHARS) {
                text = text.substring(0, MAX_DOC_SNIPPET_CHARS) + "…";
            }
            context.append("[#").append(hit.chunkId()).append("] ")
                    .append(docDisplayName(hit)).append("：\n")
                    .append(text).append("\n\n");
            used += text.length();
        }

        String prompt = "请只依据下面的资料回答问题；资料里没有的内容就直接说「资料里没有提到」，不要编造。\n\n"
                + "资料：\n" + context + "\n问题：" + question;
        try {
            ChatModel chatModel = llmModelFactoryRouter.createChatModel(buildModelSpec());
            String answer = chatModel.chat(prompt);
            return answer == null || answer.isBlank() ? "（模型没有给出回答）" : answer.strip();
        } catch (RuntimeException e) {
            // 模型不可用时至少把命中片段给用户，别让 `\doc 问题` 完全无输出
            return "模型调用失败（" + e.getMessage() + "），先给你命中的资料：\n\n" + context;
        }
    }

    /**
     * 按名字找一篇文档：先精确匹配，再包含匹配。
     *
     * @param target 用户写的名字
     * @return 命中的文档；找不到时为 null
     */
    private RagDtos.RagDocument findDoc(String target) {
        String needle = nvl(target).strip();
        if (needle.isEmpty()) {
            return null;
        }
        List<RagDtos.RagDocument> documents = ragService.listDocuments(DOC_LIST_LIMIT, 0);
        // 第一轮：完全相等（忽略大小写），避免「报告」误删「年度报告」
        for (RagDtos.RagDocument document : documents) {
            if (needle.equalsIgnoreCase(docDisplayName(document))) {
                return document;
            }
        }
        // 第二轮：包含匹配，允许用户只写文件名的一部分
        for (RagDtos.RagDocument document : documents) {
            if (docDisplayName(document).contains(needle)) {
                return document;
            }
        }
        return null;
    }

    /**
     * 取文档的展示名：标题 → 文件名 → 来源。
     *
     * @param document 文档
     * @return 展示名；永不为 null
     */
    private static String docDisplayName(RagDtos.RagDocument document) {
        if (document.title() != null && !document.title().isBlank()) {
            return document.title();
        }
        if (document.name() != null && !document.name().isBlank()) {
            return document.name();
        }
        return nvl(document.source());
    }

    /**
     * 取检索命中的展示名：标题 → 来源。
     *
     * @param hit 检索命中
     * @return 展示名；永不为 null
     */
    private static String docDisplayName(RagDtos.SearchHit hit) {
        if (hit.title() != null && !hit.title().isBlank()) {
            return hit.title();
        }
        return nvl(hit.source());
    }
```

```java
// Hutool：生成短随机串，拼出唯一的子会话 id
import cn.hutool.core.util.IdUtil;

import dev.langchain4j.agent.tool.ToolExecutionRequest;

import java.util.List;

/**
 * 子 agent 运行器的最小实现。
 *
 * <p><b>能力边界：</b>只给只读工具（{@code ToolRegistry#listForScope(true)}），
 * 权限模式固定 {@code ask}，作用域固定 {@code SCOPE_SUB}；它**不能写盘、不能执行命令、不能联网**。</p>
 *
 * <p><b>隔离手段：</b>每次派发都生成一个新的子会话 id（{@code 主会话-sub-随机后缀}），
 * 审计、预算、轨迹都会落在子会话名下，主对话只收到一段结论。</p>
 */
@Slf4j
@Component
public class SimpleSubAgentRunner implements SubAgentRunner {

    /** 子 agent 的工具循环上限：比主对话小，避免子任务无限自我循环。 */
    private static final int MAX_ROUND_TRIPS = 8;

    /** 子 agent 的系统提示词：把「只读、只回结论」写死，避免它模仿主对话去改文件。 */
    private static final String SUB_SYSTEM_PROMPT = """
            你是一个只读的调研子 agent。
            你只能使用只读工具（读文件、列目录、搜索），不能写盘、不能执行命令、不能联网。
            请围绕给定的子任务尽快得出结论：先用最少的工具调用收集证据，再给出结论。
            结论要求：先给 1~3 句直接回答，再列关键证据（文件路径 + 行号或片段）。
            不要输出寒暄，不要罗列你调用了哪些工具。
            """;

    /** 工具参数 schema：与主对话一致，允许模型按工具说明自行组织字段。 */
    private static final JsonObjectSchema OPEN_PARAMETERS = JsonObjectSchema.builder()
            // AgentTool 目前没有字段级参数声明，先允许任意字段，避免把模型的合法参数全部拒掉
            .additionalProperties(true)
            .build();

    /** 工具注册表：只读工具清单的来源。 */
    private final ToolRegistry toolRegistry;

    /** 设置注册表：模型名 / 接口地址 / 密钥名 / 权限模式。 */
    private final SettingsRegistry settingsRegistry;

    /** 供应商清单：默认地址、密钥名、是否必须配置密钥。 */
    private final LlmProviderRegistry llmProviderRegistry;

    /** 密钥仓库：取 API Key。 */
    private final SecretStore secretStore;

    /** 模型工厂路由：按供应商创建同步模型。 */
    private final LlmModelFactoryRouter llmModelFactoryRouter;

    /**
     * 构造器注入。
     *
     * @param toolRegistry          工具注册表
     * @param settingsRegistry      设置注册表
     * @param llmProviderRegistry   供应商清单
     * @param secretStore           密钥仓库
     * @param llmModelFactoryRouter 模型工厂路由
     */
    public SimpleSubAgentRunner(ToolRegistry toolRegistry,
                                SettingsRegistry settingsRegistry,
                                LlmProviderRegistry llmProviderRegistry,
                                SecretStore secretStore,
                                LlmModelFactoryRouter llmModelFactoryRouter) {
        this.toolRegistry = toolRegistry;
        this.settingsRegistry = settingsRegistry;
        this.llmProviderRegistry = llmProviderRegistry;
        this.secretStore = secretStore;
        this.llmModelFactoryRouter = llmModelFactoryRouter;
    }

    /**
     * 子 agent 的同步助手接口：AiServices 按它生成代理。
     */
    public interface SubAssistant {

        /**
         * 跑一轮同步工具循环并返回最终回答。
         *
         * @param userMessage 子任务描述 + 主对话补充的背景
         * @return 结论文本
         */
        String chat(String userMessage);
    }

    /**
     * 跑一个只读子任务并返回结论文本。
     *
     * @param task      子任务描述
     * @param context   主对话补充的背景；可为空
     * @param sessionId 主对话会话 id（据此派生子会话 id）
     * @return 子 agent 的结论；失败时返回一段可读的说明而不是抛异常
     */
    @Override
    public String run(String task, String context, String sessionId) {
        if (StrUtil.isBlank(task)) {
            return "";
        }
        String subSessionId = subSessionIdOf(sessionId);
        try {
            LlmModelSpec spec = buildModelSpec();
            ChatModel chatModel = llmModelFactoryRouter.createChatModel(spec);

            SubAssistant assistant = AiServices.builder(SubAssistant.class)
                    .chatModel(chatModel)
                    .systemMessage(SUB_SYSTEM_PROMPT)
                    .tools(buildReadOnlyTools(subSessionId))
                    .maxToolCallingRoundTrips(MAX_ROUND_TRIPS)
                    .build();

            // 在本线程设置子会话上下文：工具执行时 ToolRuntime 从这里读 session/scope/权限
            ToolSession.setSessionId(subSessionId);
            ToolSession.setAgentScope(ToolSession.SCOPE_SUB);
            ToolSession.setContext(new SessionContext(
                    subSessionId,
                    // 工作区白名单沿用全局配置
                    PathPolicy.workspaceRoots(),
                    // 本会话没有额外禁用的工具
                    Set.of(),
                    // 子 agent 不放行任何命令前缀（它本来也拿不到执行工具）
                    Set.of(),
                    // 工作区 id 尚未落地，保留空串
                    "",
                    // 子 agent 一律走最严权限：任何有副作用的操作都会弹确认
                    "ask",
                    ToolSession.SCOPE_SUB));

            String answer = assistant.chat(buildUserMessage(task, context));
            return answer == null ? "" : answer.strip();
        } catch (ApiException e) {
            // 配置类问题（没填密钥 / 供应商不存在）：把可读原因交给主对话，让它自己决定要不要继续
            return "子 agent 启动失败：" + e.getMessage();
        } catch (RuntimeException e) {
            log.warn("子 agent 执行失败 subSession={}：{}", subSessionId, e.getMessage(), e);
            return "子 agent 执行失败：" + e.getMessage();
        } finally {
            // 线程会被复用：不清会把子会话上下文串到下一轮
            ToolSession.clear();
        }
    }

    /**
     * 组装只读工具表：{@code listForScope(true)} 已经过滤掉写盘 / 执行类工具。
     *
     * @param subSessionId 子会话 id
     * @return ToolSpecification → ToolExecutor 的映射
     */
    private Map<ToolSpecification, ToolExecutor> buildReadOnlyTools(String subSessionId) {
        Map<ToolSpecification, ToolExecutor> tools = new LinkedHashMap<>();
        for (AgentTool tool : toolRegistry.listForScope(true)) {
            ToolSpecification specification = ToolSpecification.builder()
                    .name(tool.name())
                    .description(tool.description())
                    .parameters(OPEN_PARAMETERS)
                    .build();
            // 工具执行可能发生在模型 SDK 的回调线程：执行器里重新设置一次上下文，别依赖 run() 的 ThreadLocal
            tools.put(specification, (request, memoryId) -> executeTool(tool, request, subSessionId));
        }
        return tools;
    }

    /**
     * 执行一次工具调用。
     *
     * @param tool         被调用的工具
     * @param request      模型给出的调用请求（含 JSON 参数）
     * @param subSessionId 子会话 id
     * @return 工具结果文本（已带 OK: / FAIL: 前缀）
     */
    private String executeTool(AgentTool tool, ToolExecutionRequest request, String subSessionId) {
        Map<String, Object> arguments;
        try {
            String json = request.arguments();
            // 模型有时会省略参数：按空对象处理，让工具自己给出「缺少哪个参数」
            arguments = StrUtil.isBlank(json)
                    ? Map.of()
                    : JsonUtils.parse(json, new TypeReference<Map<String, Object>>() { });
        } catch (RuntimeException e) {
            // 参数不合法属于模型可自行修正的错误：回 FAIL 让它重试
            return ToolResult.fail(tool.name() + " 参数不是合法 JSON 对象: " + e.getMessage()).content();
        }

        ToolSession.setSessionId(subSessionId);
        ToolSession.setAgentScope(ToolSession.SCOPE_SUB);
        ToolSession.setContext(new SessionContext(
                subSessionId,
                PathPolicy.workspaceRoots(),
                Set.of(),
                Set.of(),
                "",
                "ask",
                ToolSession.SCOPE_SUB));
        try {
            return tool.execute(arguments).content();
        } catch (RuntimeException e) {
            // ToolRuntime 已把业务异常转成 FAIL；这里再兜一层，避免异常冒到框架回调
            return ToolResult.fail(tool.name() + " 执行失败: " + e.getMessage()).content();
        }
    }

    /**
     * 拼子任务消息：任务描述 + 主对话补充的背景。
     *
     * @param task    子任务描述
     * @param context 主对话补充的背景；可为空
     * @return 发给子 agent 的用户消息
     */
    private static String buildUserMessage(String task, String context) {
        if (StrUtil.isBlank(context)) {
            return "子任务：\n" + task;
        }
        return "子任务：\n" + task + "\n\n主对话补充的背景：\n" + context;
    }

    /**
     * 生成子会话 id：主会话 id + "-sub-" + 8 位随机串。
     *
     * @param sessionId 主会话 id；可为空
     * @return 子会话 id
     */
    private static String subSessionIdOf(String sessionId) {
        String suffix = IdUtil.fastSimpleUUID().substring(0, 8);
        String prefix = StrUtil.isBlank(sessionId) ? "sub" : sessionId + "-sub";
        return prefix + "-" + suffix;
    }

    /**
     * 按当前设置装配模型参数（与 ChatServiceImpl#buildModelSpec 保持一致的取值顺序）。
     *
     * @return 模型装配参数
     * @throws ApiException 供应商未知、没有模型或缺少密钥时
     */
    private LlmModelSpec buildModelSpec() {
        String providerId = String.valueOf(settingsRegistry.getSetting("llm.provider"));
        String modelName = String.valueOf(settingsRegistry.getSetting("llm.model")).trim();

        LlmDtos.ProviderInfo provider = llmProviderRegistry.findProvider(providerId)
                .orElseThrow(() -> new ApiException(404, "未知的模型供应商：" + providerId));
        if (modelName.isEmpty()) {
            if (provider.models().isEmpty()) {
                throw new ApiException(404, "供应商 " + providerId + " 还没有配置任何模型");
            }
            modelName = provider.models().get(0).model();
        }

        String apiKey = null;
        if (!StrUtil.isBlank(provider.secretKey())) {
            apiKey = secretStore.getSecret(provider.secretKey()).orElse(null);
        }
        if (provider.requiresKey() && StrUtil.isBlank(apiKey)) {
            throw new ApiException(400, "尚未配置 " + provider.label() + " 的 API 密钥，"
                    + "请到设置页的「模型」分区填写（对应设置项：" + provider.secretKey() + "）");
        }

        // 接口地址：自定义端点用自己的地址，内置供应商保持「全局配置优先」
        String configuredBaseUrl = String.valueOf(settingsRegistry.getSetting("llm.base_url"));
        String baseUrl = provider.isCustom()
                ? provider.baseUrl()
                : (configuredBaseUrl.isBlank() ? provider.baseUrl() : configuredBaseUrl.trim());

        Double temperature = ((Number) settingsRegistry.getSetting("llm.temperature")).doubleValue();
        int configuredMaxTokens = ((Number) settingsRegistry.getSetting("llm.max_tokens")).intValue();
        Integer maxTokens = configuredMaxTokens > 0 ? configuredMaxTokens : null;

        return new LlmModelSpec(providerId, modelName, apiKey, baseUrl, temperature, maxTokens);
    }
}
```

## 8. 2.10 MCP SSE：当前依赖版本做不到

**核对证据**（`langchain4j-mcp 1.22.0-beta32` 的 jar 内容）：

```
dev/langchain4j/mcp/client/transport/StdioMcpTransport.class
dev/langchain4j/mcp/client/transport/StreamableHttpMcpTransport.class
dev/langchain4j/mcp/client/transport/WebSocketMcpTransport.class
dev/langchain4j/mcp/client/transport/... (internal/SseSubscriber 等内部类)
```

**结论**：这个版本**没有** SSE 传输类，只有 `streamable_http`。
`McpServiceImpl#buildTransport` 里 `case "sse"` 抛 `UnsupportedOperationException` 是正确的兜底，
**不要**为了「补齐」而硬写一个假的 SSE 分支。

**推荐做法（不改代码）**

- 在 MCP 服务配置里把 `"transport": "sse"` 改成 `"transport": "streamable_http"`；
- 绝大多数 MCP Server 同时提供两者，改配置即可。

**如果对方只支持 SSE**，只有两条路，都属于「独立任务」而不是本清单的补丁：

1. 升级 `langchain4j-mcp` 到提供了 SSE 传输的版本（需要同步升级 `langchain4j` 主版本，回归面很大）；
2. 自己实现 `McpTransport` 接口（手写 SSE 长连接 + JSON-RPC 帧解析），约数百行，且要自己处理重连。

## 9. 2.9 LangGraph4j 图：建议继续暂缓

**为什么不给代码**：当前同进程内的「确认 / 恢复 / 终止」由 `ChatSessionBus` 的内存等待实现，
已经覆盖了**进程不重启**的全部场景；上图的唯一收益是「进程重启后从断点续跑」和「计划模式」，
而这两件事都需要先有「检查点存储 + 计划事件协议」，不是一段可粘贴的方法能解决的。

如果确实要做，按下面的顺序推进（每一步都能单独验收）：

1. **先补事件**：`ChatEvents` 增加 `plan` / `plan_update` / `task_start` / `task_end` 四个工厂方法
   （枚举里已经有 `ChatEventType`，只差载荷 record）；
2. **再补检查点**：新增 `agent_checkpoint` 表（`thread_id` / `turn_id` / `node` / `state_json`），
   实现 LangGraph4j 的 `CheckpointSaver`；
3. **最后接图**：`AgentGraphConfig#agentGraph()` 用 `StateGraph` 串
   「prepare → model → tools → decide」四个节点，并在 `ChatServiceImpl#runTurn` 里按开关二选一：
   开关关闭走现在的 `AiServices` 工具循环（默认），打开才走图；
4. **必须保留回退开关**：图出问题时能一键切回 `AiServices`，否则一次线上回归就会让整个对话不可用。
